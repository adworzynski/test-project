# Keel artifacts

One Markdown file per artifact, with YAML front-matter (id, type, status, links, owner, created, updated).
Sections whose heading starts with an ID (`### FR-001: …`, `### AC-001: …`, `### SC-001: …`) are artifacts too.

| Folder | Holds |
| --- | --- |
| brief/ | one-page brief (BR) |
| prd/ | PRD with FR/NFR requirements (PRD) |
| screens/ | screen map with SC screens (SM) |
| tokens/ | design tokens (DT) |
| adr/ | decision records (ADR) |
| stories/ | stories with AC criteria (ST) |
| changes/ | Quick and Feature changes with deltas (CH); merged ones in changes/archive/ |
| release/ | release checklists (RL) |
| sources/ | imported source documents (SRC) |
