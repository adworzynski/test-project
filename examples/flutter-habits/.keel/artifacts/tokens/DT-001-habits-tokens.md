# DT-001: Habits tokens

Text and background pairs must meet WCAG 2.2 AA contrast (4.5:1 for body text).

```yaml
color:
  primary: "#3355FF"
  on-primary: "#FFFFFF"
  surface: "#FFFFFF"
  on-surface: "#1B1B1F"
  error: "#B3261E"
typography:
  body: { family: "System", size: 16, weight: 400 }
  title: { family: "System", size: 22, weight: 600 }
spacing: [4, 8, 12, 16, 24, 32]
radius: { small: 4, medium: 8, large: 16 }
```
